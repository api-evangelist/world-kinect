# World Kinect

> World Kinect Corporation (NYSE: WKC), formerly World Fuel Services, is a Fortune 500 energy,
> commodities and services company headquartered in Doral, Florida. It supplies and manages
> aviation, marine and land fuel, lubricants, natural gas, power, water and carbon-management
> services in more than 200 countries.

## What is machine-readable today

World Kinect publishes **no public API contract**. As of 2026-09-04 there is no developer portal,
no API reference, and no OpenAPI, AsyncAPI, GraphQL SDL, WSDL, Protobuf, MCP server or A2A agent
card on any host this profile knows — world-kinect.com, wfscorp.com and the myWorld portal hosts,
coltinternational.com, logintokinect.com, flyersenergy.com or quickfuel.com. `/llms.txt`,
`/openapi.json`, `/swagger.json` and every `/.well-known/` path either 404 or return an
application shell.

An API does exist. World Fuel's fuel-price and AVCARD surface is consumed by third-party
flight-operations platforms (Leon Software, Schedaero FuelFinder, Satcom Direct SD Pro), and the
myWorld and World Kinect Online portals are API-backed single-page applications. All of it is
reachable only under an existing customer agreement, through the portal-access request form.
